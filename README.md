# munin-web

Marketing website + privacy policy for **Munin** ("Munin: Gratitude Journal"), the
iOS gratitude journal app.

Built with [Astro](https://astro.build/), deployed as a static site on Vercel.

## Local development

```bash
npm install
npm run dev
```

Then open the URL Astro prints (default http://localhost:4321).

## Build

```bash
npm run build      # output in dist/
npm run check      # typecheck
```

## Deploy

Connect this repo to Vercel — Astro is auto-detected, no configuration needed.
Every push to the main branch publishes automatically.

See [CLAUDE.md](./CLAUDE.md) for project rules and open items.
